This catalog contains 20 structured, risk-ranked test cases generated by CoreBank QA Agent for domestic fund transfers.

### TC-FT-001: Valid Fund Transfer within Available Balance and Daily Limit
- **Requirement ID:** REQ-PAY-FT-001 (AC-01, AC-04, AC-05, AC-06, AC-08)
- **Risk Level / Priority:** Critical / P0
- **Test Type:** Happy Path / End-to-End Financial Flow
- **Preconditions:** Source account `ACCT-CHK-001` active with $5,000.00 available balance; Beneficiary `BENEF-001` active.
- **Test Data:** Amount: $250.00 USD, Idempotency-Key: `IDEMP-FT-001-AUTO`.
- **Test Steps:**
  1. Authenticate user and navigate to Fund Transfer page.
  2. Select source account `XXXXXXXX1234` and beneficiary `XXXXXXXX5678`.
  3. Enter amount `250.00` and submit transfer.
  4. Capture transaction confirmation reference.
- **Expected UI Result:** Success banner displayed with unique Transaction ID, transfer status `COMPLETED`, balance refreshed.
- **Expected API Result:** HTTP 200 OK with payload `{"status":"COMPLETED","transactionRef":"TXN-20260510-984372","amount":250.00}`.
- **Expected Transaction/Ledger Result:** Source account balance debited exactly $250.00; Beneficiary balance credited $250.00; Ledger net variance is 0.00.
- **Expected Audit Result:** Audit log contains `EVENT_TRANSFER_COMPLETED` with masked account references.
- **Recommended Tool:** Playwright + API + Reconciliation Validation
- **Tags:** `@smoke @critical @fund-transfer @happy-path`
- **Assumptions:** Zero transfer fees for standard domestic ACH/Wire.
